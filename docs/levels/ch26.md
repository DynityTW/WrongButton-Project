# 第 26 章　排順序（401–420）

> 由 `tools/s2/gen.py` 依 `tools/s3/ch26.py` 產生。

**主題**：排隊。幾顆按鈕由左到右排成一排（第 1、2、3……個），根據線索排出唯一的順序。
第 408 關起，每一顆還在飲料店買了一種飲料，順序和飲料都要排對。

- 線索種類：排第幾個／不是第幾個、在誰的左邊（不一定相鄰）、緊貼在右邊、相鄰／不相鄰、在兩端／不在兩端、
  中間剛好隔一個、在兩顆中間；飲料：買的是／不是什麼、在買某飲料的左邊、和買某飲料的相鄰。
- 橘色的線索要聽 The Button 說，說謊時那條線索是假的。第 411、415、416 關看不到臉，只知道剛好一條是假的。

題目由 `tools/s3/order.py` 產生：暴力列舉所有排法（最多 120×120 種），答案唯一、每一條線索都用得到，
只看一半的線索還有很多種排法；「排第幾個」這種直接的線索有數量上限（第 412、414、416、419 關完全沒有）。

**本章規則**：排錯算一次錯。點格子換按鈕／換飲料。

### 401〈排隊〉
- **任務**：把大家排好。
- **畫面**：四顆按鈕、幾條線索。
- **解法**：依線索排出順序。
- **線索**：線索。
- **提示**：①「先用最確定的線索，把一顆放到固定的位置。」②「「在兩端」只有兩種可能；「不是第幾個」會刪掉一種。」③「答案（由左到右）：黃鈕、紅鈕、藍鈕、綠鈕。」
- **備註**：線索：黃鈕在紅鈕的左邊（不一定相鄰）。　紅鈕排第 2 個。　綠鈕和紅鈕不相鄰。 答案（由左到右）：黃鈕、紅鈕、藍鈕、綠鈕。
