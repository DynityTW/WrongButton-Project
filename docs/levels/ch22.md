# 第 22 章　我不是機器人（321–340）

> 由 `tools/s2/gen.py` 依 `tools/s3/ch22.py` 產生。

**主題**：「我不是機器人」驗證。勾選框打開後是一張九宮格（後面是 4×4），上面有幾句關於正確答案的話。
選出唯一符合的格子，按「驗證」。每一關有一到三題，全部通過後勾選框會打勾，再按 The Button。

**題目**：每一題都由 `tools/s3/captcha.py` 產生並用暴力法檢查過：
- 答案唯一，而且每一句話都用得到（拿掉任何一句，答案就不唯一）。
- 句子的種類：每一格都是……、所有……都要選、沒有……、剛好選幾格、剛好幾格是……、圖形加起來幾個、格子編號加起來、
  每一列／每一行剛好一格、不能相鄰、第幾格要選／不要選。
- 第 325 關：「選出所有……」由 The Button 說；說謊時要選的剛好是相反的那些。
- 要聽它說的關卡（329、333、337、340）：謊話＝那句話是假的。把謊話當真一定會選錯。
- 看不到臉的關卡（330、334、338、340 第二題）：只知道剛好幾句是真的。

**本章規則**：驗證失敗算一次錯（選取會保留）。還沒通過驗證就按 The Button 也算錯。
