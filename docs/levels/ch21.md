# 第 21 章　踩地雷（301–320）

> 由 `tools/s2/gen.py` 依 `tools/s3/ch21.py` 產生。

**主題**：踩地雷。翻開格子會看到數字：周圍八格（第 308、311、316 關只算上下左右）裡有幾顆雷。翻開所有安全的格子，再按 The Button 就通關。
插旗模式的關卡只能插旗，要把每一顆雷都標出來。

**The Button 說的數字**：有些格子是「?」，點一下 The Button 會說出那格的數字。說謊的時候臉會露餡（眼睛看旁邊、一邊嘴角翹起）。
謊話也是線索：真正的數字一定**不是**它說的那個。第 314、319 關看不到它的臉，數字寫在紙條上，只知道剛好幾張是假的。

**難度**：每一張盤面都是固定的，由 `tools/s3/mines.py` 產生並檢查過：
- 不需要猜：每一步都至少有一格可以靠邏輯確定。
- 後半章每張都有好幾步「單看一個數字推不出來」，要把幾個數字（或謊話、剩餘雷數）放在一起想。
- 有謊話的盤面，把謊話當真一定會推錯。

**本章規則**：踩到雷算一次錯，那格會標成地雷，可以繼續。插旗模式插錯算一次錯。還沒掃完就按 The Button 也算錯。
