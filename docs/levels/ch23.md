# 第 23 章　誰在說謊（341–360）

> 由 `tools/s2/gen.py` 依 `tools/s3/ch23.py` 產生。

**主題**：說真話的人與說謊的人。幾顆沒有臉的按鈕（紅鈕、藍鈕、綠鈕……）各說一兩句話。
每一顆不是「永遠說真話」，就是「永遠說謊」。點按鈕可以標記，選好按「確定」。

- 找出所有說謊的（大部分的關卡）。
- 找出 The Button 的「分身」（344、353、354、360）：分身混在裡面，它可能說真話也可能說謊。也要標出所有說謊的。
- 找出間諜（349、358）：間諜想說什麼就說什麼，它的話不能當線索。也要標出所有說謊的。
- 找分身、找間諜時也要標說謊的，是為了不能一顆一顆試；產生器確認連說謊的是哪幾顆也只有一種答案。
- The Button 本人也說一句（350、357、360）：這一句有臉可以讀；墨鏡、口罩的關卡只剩一半的臉。

**題目**：由 `tools/s3/liars.py` 產生，暴力檢查所有身分組合：答案唯一、每一句話（一人兩句的關卡是每一個人）都用得到，
而且只拿一半的句子時一定還有好幾種可能，不會一兩句就看穿。「X 是說謊的」這種直接的句子有數量上限。

**本章規則**：按「確定」時標記不對算一次錯（標記保留）。The Button 有說話的關卡，要先聽它說。

### 341〈兩顆〉
- **任務**：找出說謊的按鈕。
- **畫面**：兩顆按鈕，各說一句。
- **解法**：假設、檢查矛盾，標記說謊的。
- **線索**：兩句話之間的矛盾。
- **提示**：①「說真話的說的話一定是真的；說謊的說的話一定是假的。」②「假設紅鈕說真話，看藍鈕的話對不對得上；再假設紅鈕說謊試一次。」③「答案：紅鈕。」
- **備註**：題目：紅鈕：我和藍鈕是同一種。　藍鈕：紅鈕是說謊的。。身分：LT。

### 342〈三顆〉
- **任務**：找出說謊的按鈕。
- **畫面**：三顆按鈕，各說一句。
- **解法**：假設＋檢查。
- **線索**：句子之間的關係。
- **提示**：①「三顆，一顆一句。說謊的可能不只一顆。」②「從說「X 和 Y 是同一種」的那句開始：它說真話時，X、Y 同種。」③「答案：紅鈕、藍鈕。」
- **備註**：題目：紅鈕：藍鈕不是說謊的。　藍鈕：綠鈕不是說真話的。　綠鈕：紅鈕和藍鈕是同一種。。身分：LLT。

### 343〈誰〉
- **任務**：找出說謊的按鈕。
- **畫面**：三顆按鈕，各說一句。
- **解法**：找出衝突，再推其他。
- **線索**：衝突。
- **提示**：①「兩顆按鈕說的話互相衝突時，至少一顆在說謊。」②「紅鈕和藍鈕對綠鈕的說法相反：它們一定不是同一種。」③「答案：藍鈕。」
- **備註**：題目：紅鈕：綠鈕是說真話的。　藍鈕：綠鈕是說謊的。　綠鈕：我和紅鈕是同一種。。身分：TLT。

### 344〈分身〉
- **任務**：找出 The Button 的分身，和所有說謊的。
- **畫面**：三顆按鈕，其中一顆是 The Button 的分身。
- **解法**：推出身分，再找分身。
- **線索**：關於分身的那句話。
- **提示**：①「我的分身混在這三顆裡。它跟其他按鈕一樣，不是說真話就是說謊。」②「先決定誰說真話、誰說謊，再看「分身是……」那句能不能信。」③「答案：綠鈕；說謊的：綠鈕。」
- **備註**：題目：紅鈕：藍鈕是說真話的。　藍鈕：分身是說謊的。　綠鈕：我和紅鈕是同一種。。身分：TTL。

### 345〈同一種〉
- **任務**：找出說謊的按鈕。
- **畫面**：四顆按鈕，句子都是「同一種／不是同一種」。
- **解法**：假設紅鈕的身分，沿著關係推下去。
- **線索**：同種／不同種的關係。
- **提示**：①「這次每一句都在說「誰和誰是不是同一種」。」②「說謊的人說「X 和 Y 是同一種」，代表 X、Y 其實不同。」③「答案：綠鈕、黃鈕。」
- **備註**：題目：紅鈕：黃鈕和藍鈕不是同一種。　藍鈕：黃鈕和綠鈕是同一種。　綠鈕：我和藍鈕是同一種。　黃鈕：紅鈕和綠鈕是同一種。。身分：TTLL。

### 346〈數一數〉
- **任務**：找出說謊的按鈕。
- **畫面**：四顆按鈕。
- **解法**：用數量的句子縮小範圍。
- **線索**：數量。
- **提示**：①「四顆，有「我們之中剛好有幾個說謊的」這種句子。」②「數量的句子很強：先假設說謊的有幾個，再看誰的話對不上。」③「答案：藍鈕、綠鈕。」
- **備註**：題目：紅鈕：黃鈕和藍鈕不是同一種。　藍鈕：綠鈕和紅鈕是同一種。　綠鈕：藍鈕和黃鈕是同一種。　黃鈕：綠鈕和紅鈕不是同一種。。身分：TLLT。

### 347〈如果〉
- **任務**：找出說謊的按鈕。
- **畫面**：四顆按鈕，有一句「如果……」。
- **解法**：用「如果」句的真假推出兩顆的身分。
- **線索**：如果句。
- **提示**：①「「如果 X 說真話，那 Y 也說真話」只有一種情況是假的：X 說真話、Y 說謊。」②「所以說謊的人說這句話時，X 一定說真話、Y 一定說謊。」③「答案：紅鈕、綠鈕、黃鈕。」
- **備註**：題目：紅鈕：如果藍鈕說真話，那綠鈕也說真話。　藍鈕：綠鈕是說謊的。　綠鈕：黃鈕和藍鈕是同一種。　黃鈕：藍鈕是說謊的。。身分：LTLL。

### 348〈一人兩句〉
- **任務**：找出說謊的按鈕。
- **畫面**：三顆按鈕，各說兩句。
- **解法**：用兩句一致的規則推理。
- **線索**：同一顆的兩句話。
- **提示**：①「每一顆說兩句。同一顆說的兩句，不是都真就是都假。」②「只要其中一句明顯是假的，另一句也是假的。」③「答案：藍鈕。」
- **備註**：題目：紅鈕：我們之中剛好有 1 個說謊的。　紅鈕：藍鈕和綠鈕不是同一種。　藍鈕：紅鈕和綠鈕之中，至少一個說謊。　藍鈕：綠鈕和紅鈕不是同一種。　綠鈕：我們之中至少有 2 個說真話的。　綠鈕：紅鈕和藍鈕不是同一種。。身分：TLT。

### 349〈間諜〉
- **任務**：找出間諜，和所有說謊的。
- **畫面**：三顆按鈕，其中一顆是間諜。
- **解法**：逐一假設間諜，找出唯一不矛盾的情況。
- **線索**：矛盾。
- **提示**：①「有一顆是間諜：它的話可真可假，不能當線索。」②「分別假設每一顆是間諜，把另外兩顆當成普通的說真話／說謊的，看會不會矛盾。」③「答案：藍鈕；說謊的：紅鈕、綠鈕。」
- **備註**：題目：紅鈕：我和藍鈕是同一種。　藍鈕：我和綠鈕是同一種。　綠鈕：藍鈕和紅鈕是同一種。。身分：LSL。

### 350〈它也說了〉
- **任務**：找出說謊的按鈕。
- **畫面**：四顆按鈕，加上 The Button 本人的一句（謊話）。
- **解法**：讀臉，把 The Button 的謊話反過來當線索。
- **線索**：臉。
- **提示**：①「這關我也說一句。說謊的時候我的眼睛會看旁邊、一邊嘴角翹起。」②「我的那句如果是謊話，它的相反才是真的，也是一條線索。」③「我那句是謊話。答案：藍鈕、綠鈕、黃鈕。」
- **備註**：題目：紅鈕：藍鈕和黃鈕是同一種。　藍鈕：我們之中剛好有 1 個說謊的。　綠鈕：我們之中至少有 2 個說真話的。　黃鈕：我和紅鈕是同一種。；The Button：我們之中剛好有 2 個說謊的。（謊話）。身分：TLLL。

### 351〈排成一列〉
- **任務**：找出說謊的按鈕。
- **畫面**：五顆按鈕排成一列，有「我旁邊……」的句子。
- **解法**：從兩端推到中間。
- **線索**：位置。
- **提示**：①「它們排成一列：紅、藍、綠、黃、紫。「我旁邊」是左右相鄰的。」②「最旁邊的只有一個鄰居。從兩端開始想。」③「答案：藍鈕、綠鈕、黃鈕、紫鈕。」
- **備註**：題目：紅鈕：我旁邊的藍鈕說謊。　藍鈕：我旁邊的兩個是同一種。　綠鈕：黃鈕和紅鈕是同一種。　黃鈕：我們之中剛好有 1 個說謊的。　紫鈕：藍鈕是說真話的。。身分：TLLLL。

### 352〈它會怎麼說〉
- **任務**：找出說謊的按鈕。
- **畫面**：四顆按鈕，兩句是「如果你問 X，它會說我是說謊的」。
- **解法**：把轉述句化簡成「不同種」，再推理。
- **線索**：轉述句。
- **提示**：①「「如果你問 X，它會說我是說謊的」：不管誰說真話，這句話都代表說話的和 X 不是同一種。」②「想想看：說真話的被誠實地指控，或說謊的被說謊者指控……」③「答案：藍鈕、綠鈕。」
- **備註**：題目：紅鈕：如果你問藍鈕，它會說我是說謊的。　藍鈕：如果你問綠鈕，它會說我是說謊的。　綠鈕：藍鈕和紅鈕是同一種。　黃鈕：綠鈕是說謊的。。身分：TLLT。

### 353〈找分身〉

### 358〈間諜說兩句〉

### 360〈誰在說謊〉
- **任務**：找出 The Button 的分身，和所有說謊的。
- **畫面**：六顆按鈕：一顆間諜、一顆分身；The Button 戴口罩說一句（謊話）。
