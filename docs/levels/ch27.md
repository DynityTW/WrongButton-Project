# 第 27 章　迷宮（421–440）

> 由 `tools/s2/gen.py` 依 `tools/s3/ch27.py` 產生。

**主題**：跳格迷宮。從左上角（A1）出發，走到 The Button 那一格。
- 數字 k：往上下左右其中一個方向，剛好跳 k 格。
- 箭頭：往箭頭的方向走，幾格都可以（不能出界）。
- 步數有上限，剛好是最短路線的長度；上限內只有一條路線走得到。
- 橘色的箭頭要聽 The Button 說；說謊時，真正的方向是相反的（正確路線一定會經過說謊的箭頭）。

由 `tools/s3/maze.py` 產生：BFS 檢查最短路線唯一，而且從起點走得到的格子很多（死路很多）。

**本章規則**：點一格就是跳過去。跳不到的格子算一次錯；步數用完還沒到也算一次錯，回到起點。「重來」不算錯。

### 421〈跳格子〉
- **任務**：走到我這裡。最多 4 步。
- **畫面**：4×4，每一格一個數字。
- **解法**：倒著推出路線。
- **線索**：數字。
- **提示**：①「數字是剛好要跳幾格，方向自己選。」②「倒著想：先找出哪些格子能一步跳到我這裡，再找哪些格子能跳到那些格子。」③「路線：A1 → B1 → B2 → B3 → C3。」
- **備註**：路線：A1 → B1 → B2 → B3 → C3。從起點走得到 16 格。
