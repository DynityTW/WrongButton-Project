# 第 25 章　開關與線路（381–400）

> 由 `tools/s2/gen.py` 依 `tools/s3/ch25.py` 產生。

**主題**：看不到的電線。幾個開關（A–E）接到幾盞燈（1–5），接法看不到。畫面上是之前做過的實驗：開了哪些開關、哪些燈亮。
推出唯一一組開關，讓「目標」的燈剛好亮、其他燈都暗，按「通電」。

- **並聯（381–385、389、390、392、394、396、399）**：燈接到的開關只要有一個打開，燈就亮。
- **切換（386–388、391、393、395、397、398、400）**：燈接到的開關每打開一個，燈就切換一次；開兩個接到同一盞燈的開關，燈又暗了。
- 橘色問號的燈要點一下聽 The Button 說；說謊時亮暗相反。第 394、395、399、400 關看不到臉，只知道剛好一格是假的。

題目由 `tools/s3/wires.py` 產生：每盞燈的接法獨立列舉，不管電線實際怎麼接（只要和實驗一致），答案都是同一組開關，
也沒有別組開關可能剛好成功；每一次實驗都用得到；謊話當真會得到錯的答案。

**本章規則**：通電但燈不對算一次錯（不會告訴妳哪裡不對，免得用試的）。有橘色問號的關卡要全部聽完才能通電。

### 381〈電線〉
- **任務**：讓目標的燈亮起來，其他燈都暗。
- **畫面**：3 個開關、3 盞燈，幾次實驗。
- **解法**：推出每盞燈接了哪些開關，再選出剛好點亮目標的開關。
- **線索**：實驗結果。
- **提示**：①「並聯：燈接到的開關只要有一個開著就亮。所以「燈暗」代表那次開的開關，全都沒接到這盞燈。」②「先找出每盞燈「一定沒接到」的開關，再找「一定有接到」的。」③「打開 A。」
- **備註**：打開 A。
