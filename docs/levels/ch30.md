# 第 30 章　終章（481–500）

> 由 `tools/s2/gen.py` 依 `tools/s3/ch30.py` 產生。

**主題**：第三季的最後一章。第 21–29 章的九種謎題各出兩題最難的版本，第 500 關是最後一場「誰在說謊」。
The Button 幾乎每一關都會說謊，而且說得很自然（幅度小），常常戴著墨鏡或口罩。
