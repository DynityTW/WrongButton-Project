# 第 29 章　鏡子（461–480）

> 由 `tools/s2/gen.py` 依 `tools/s3/ch29.py` 產生。

**主題**：雷射與鏡子。雷射從左邊某一列射進格子，碰到鏡子（／或＼）會轉彎。灰底的鏡子可以點一下換方向。
把它們轉好，讓雷射射出格子時剛好打到 The Button，按「發射」。按下去之前看不到光線。

- ／：從左邊來往上、從下面來往右……（像光照到斜放的鏡子）。＼ 則相反。
- 橘色的固定鏡子要聽 The Button 說方向；說謊時方向相反（說謊的鏡子一定在光線的路上）。

由 `tools/s3/mirrors.py` 產生：列舉所有可轉鏡子的組合，只有一種打得到 The Button（所以每一面可轉的鏡子都在光線上）。

**本章規則**：發射沒打到算一次錯（不會顯示光線，免得用試的）。
