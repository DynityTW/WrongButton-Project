# 第 28 章　密碼規則（441–460）

> 由 `tools/s2/gen.py` 依 `tools/s3/ch28.py` 產生。

**主題**：「請設定密碼」。幾位數字（3–5 位，可以 0 開頭），加上一串規則。設定出唯一符合所有規則的密碼。
規則旁邊**不會**即時打勾，所以不能用試的。

規則種類：數字加起來、加起來小於、相乘、哪一位比哪一位大（大多少）、兩位加起來、包含／不包含、奇數／偶數、
剛好幾位是偶數、整個密碼是幾的倍數、質數、倒過來念一樣、由小到大、相鄰不同、每一位都不一樣、最大的數字。

題目由 `tools/s3/pins.py` 產生（位元遮罩暴力列舉最多 10 萬組）：答案唯一、每一條規則都用得到、只看一半的規則還有很多組可能，
沒有「第幾位是幾」這種直接的規則。橘色的規則要聽 The Button 說（說謊時規則是假的）；第 450、454、458 關看不到臉，只知道剛好一條是假的。

**本章規則**：設定錯的密碼算一次錯。

### 441〈設定密碼〉
- **任務**：設定符合所有規則的密碼。
- **畫面**：三位數密碼、幾條規則。
- **解法**：算出唯一的密碼。
- **線索**：規則。
- **提示**：①「先用「加起來是多少」縮小範圍。」②「再用「哪一位比哪一位大」排除。」③「密碼是 269。」
- **備註**：規則：第二位比第一位大。　密碼裡有 9。　所有數字加起來是 17。　第一位不是 0。　第二位是偶數。 密碼是 269。
