# Google Play 商店資訊（繁體中文）

直接複製貼到 Play Console →「發布 → 商店資訊 → 主要商店資訊」。字數都已經在 Google 的限制內。

## 應用程式名稱（上限 30 字）

```
Wrong Button：會說謊的按鈕
```

## 簡短說明（上限 80 字）

```
一顆會說謊的按鈕。看穿它的臉，找出真正該按的那一顆。300 關、單指、不限時。
```

## 完整說明（上限 4000 字）

```
每一關的任務都只有一句：按下按鈕。
難的是，那顆按鈕會說謊。

Wrong Button 是一款解謎遊戲。畫面看起來像一個普通的 App，但裡面住著一顆會說謊、而且記得你做過什麼的按鈕——The Button。它會說「按我就對了」，會把真正的按鈕藏起來，會在你最有把握的時候改變規則。

【學會讀它的臉】
The Button 說謊的時候，眼睛會看向旁邊，一邊的嘴角會翹起來。這個特徵全遊戲永遠不變。學會讀臉，你就不會再被騙。

【App 的語言就是謎題】
下拉重新整理、返回鍵、溢位選單、預先勾選的方塊、藏在小字裡的條款、找不到的「取消訂閱」……你每天在用的介面慣例，都是解法；那些常見的介面陷阱，也都會變成關卡讓你看穿。

【它記得你】
你第一次按它花了幾秒、按錯幾次、往哪邊把它滑掉，後面的關卡都會用到。

【300 關，20 章】
・第一季（第 1–120 關）：信任問題、看我的臉、什麼才算按鈕、它記得你……
・第二季（第 121–300 關）：外面、同類、暗黑模式、按鈕語、換你做、播放中……每一章都是獨立的新玩法，打完第一季後可以從任何一章開始。

【為每個人設計】
・每一關都能用一根手指完成，不限時，不靠反應速度。
・讀臉的關卡可以只靠 TalkBack 聽到的外觀描述來推理。
・支援減少動態效果、深色模式，可以選擇它稱呼你「你」或「妳」。
・不需要帳號，不會跳出任何權限詢問，離線也能玩。你的遊戲紀錄只存在你的手機裡。

【免費與 Pro】
・前 75 關免費。
・免費版：第 1 階提示免費；第 2、3 階提示第一次看需要先看一則廣告；每通過 5 關，關卡之間會出現一則廣告。關卡進行中不會插播廣告。
・Pro（一次買斷，沒有訂閱）：解鎖第 76–300 關，並移除所有廣告。

聯絡我們：support@luarvex.com
```
